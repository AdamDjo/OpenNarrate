# Checklist avant publication

## Vidéo
- [ ] `fabriquer.py verifier` : tout est bon
- [ ] Noms propres affichés à l'écran relus
- [ ] Aucune musique, voix ou image sans droits, aucun clip d'un autre créateur
- [ ] Écran de fin présent

## YouTube
- [ ] Bonne chaîne
- [ ] Titre de 70 caractères maximum : curiosité + sujet
- [ ] Description : accroche, chapitres, question, abonnement, mention de non-affiliation si besoin
- [ ] Tags et hashtags
- [ ] Miniature (2 versions pour un test)
- [ ] « Contenu modifié ou synthétique » : Oui
- [ ] Public (enfants ou non)
- [ ] Écran de fin et playlist
- [ ] Vérification des droits : aucune réclamation

## Après
- [ ] Commentaire épinglé avec la question de la vidéo
- [ ] Répondre aux commentaires la première heure
