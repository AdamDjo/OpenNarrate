# Narrateurs

Un dossier par narrateur : `reference.wav` (8 à 20 s d'une seule personne, dans la langue de la vidéo, avec le droit de l'utiliser), `portrait.png`, `fiche.md` (caractère, façon de parler ; ligne 1 = description en anglais pour les prompts d'images).

Jamais la voix d'une personne réelle sans son accord écrit. Voir `Docs/voix.md`.
