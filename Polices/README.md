# Polices

Déposez ici deux polices à licence libre (Google Fonts, par exemple), ou indiquez leurs chemins dans `config.json` :
- `titres.ttf` : textes à l'écran, miniatures, nom de la chaîne ;
- `phrase.ttf` : petite phrase sous le nom, sur la bannière.

Chaque vidéo peut avoir sa propre police pour ses titres : déposez-la ici et indiquez-la dans `"theme_titres"` de `montage_images.json` (`"police": "Polices/ma_police.ttf"`). Vérifiez qu'elle a les accents de votre langue.

Notez chaque police et sa licence dans le `sources.md` du projet.
