# Recherche et sources

Chaque vidéo a sa fiche `sources.md` (modèle dans `Modeles/projet/`). Si un commentaire conteste un fait, on le retrouve en 10 secondes.

## Les règles
1. **15 à 25 faits numérotés**, chacun avec **2 sources**.
2. Séparer clairement :
   - **Officiel** : on l'affirme.
   - **Contradiction** : l'histoire a changé selon les versions, on le dit.
   - **Théorie** : présentée comme l'idée du narrateur (« j'ai mon idée… »).
3. Les **noms officiels** dans la langue de la vidéo, vérifiés.
4. Pour l'actualité : noter la date de la source, les infos d'avant la sortie peuvent être fausses.
5. Regarder ce qui existe déjà sur le sujet pour trouver **notre angle**. **On ne copie aucune chaîne**, ni son format ni sa structure.
6. On raconte avec nos mots. Citation courte seulement, présentée comme telle.

## Classer ses sources
Au début de `sources.md`, listez les sources du sujet de la plus fiable à la moins fiable :

| Type de source | Usage |
|---|---|
| Sources officielles, ouvrages de référence | Les faits |
| Encyclopédies spécialisées, sites reconnus | Les faits, en notant leur origine |
| Actualité datée | Ce qui vient de changer |
| Forums, Reddit | **Des pistes seulement, jamais une source** |

Si un site bloque les téléchargements automatiques, passez par le navigateur.
